设计方案预览

设备使用教程中心 · 三套企业级 UI 方案

三类方案共用同一份数据与交互（8 个设备类目、24 篇教程、139 个操作步骤），只替换视觉与布局风格。 可分别打开对比，选定后再部署上线。

方案一 · 推荐

企业专业蓝

白色顶栏 + 深蓝主色，左侧目录树、右侧内容，适合公司内网与客户侧正式使用。

  • 顶部导航 + 全局搜索（/ 快捷键）
  • 数据总览：类目 / 教程 / 步骤 / 图示视频
  • 目录树与卡片列表可一键切换
  • 教程页含右侧本页目录、上一篇 / 下一篇
打开方案一
方案二

深色精简工作台

深色顶栏 + 墨绿强调色，首页以搜索为先，适合店员 / 客服高频查教程的工作场景。

  • 大号搜索框置顶，输入型号即刻定位
  • 左侧单列紧凑目录，节省屏幕空间
  • 统计信息内嵌首屏，不占额外版面
  • 默认深色外观，可切换浅色
打开方案二
方案三

资料库编辑风

品牌蓝顶栏 + 暖白纸感底色，双栏大卡片首页，更像企业知识库与使用手册。

  • 首页首屏带「教程库概览」数据卡
  • 编号式栏目（01 / 02），阅读节奏清晰
  • 双栏大卡片目录，类目信息更完整
  • 正文排版偏纸质手册，长文更耐读
打开方案三
提示：三个方案分别位于 variants/v1-professional/、variants/v2-dark-lite/、variants/v3-editorial/，均直接双击 index.html 即可预览。
根目录 index.html 当前为方案一；选定方案后可执行 python tools/build-variants.py 重新生成，或直接把对应变体的页面复制到根目录。
