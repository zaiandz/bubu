# 移动端适配报告（2026-10）

## 一、检测方法

用 Chrome DevTools Protocol 设备模拟，覆盖 6 个页面 × 3 个宽度（320 / 375 / 414），
自动检测：横向溢出、元素超出视口、破图、触控目标尺寸、小字号文本。

## 二、检测发现与修复

### 1. 触控目标过小（最主要问题）
移动端多个按钮低于 44×44 的可点标准，手指容易点错：

| 元素 | 原尺寸 | 修复后 |
| --- | --- | --- |
| 侧栏关闭按钮 | 30×30 | **40×40** |
| 目录展开箭头 | 32×32 | **36×36** |
| 全部展开 / 收纳 | 30px 高 | **38px** |
| 目录树/卡片切换 | 26px 高 | **34px** |
| 首页网格/清单切换 | 26px 高 | **36px** |
| 租赁页筛选胶囊 | 34px 高 | **40px** |
| 租赁页弹窗关闭 | 36×36 | **40×40** |
| 品牌入口链接 | 32px 高 | **44px** |
| 正文/页脚链接 | 16px 高 | **36px**（含下划线便于识别） |

### 2. 侧栏顶部安全区缺失
移动端侧栏标题贴到屏幕最上沿，刘海屏会被状态栏遮挡。
- 所有页面 `<meta viewport>` 补上 `viewport-fit=cover`；
- 侧栏 padding 改用 `env(safe-area-inset-top / bottom)`；
- 租赁页内容底部补 `env(safe-area-inset-bottom)`，避免被 iPhone 手势条遮挡。

### 3. 租赁页筛选条横向滚动无提示
筛选胶囊超出屏幕时可横向滑动，但没有视觉提示。
- 增加 `-webkit-overflow-scrolling: touch`（iOS 惯性滚动）；
- 加 `scroll-snap-type` 让胶囊吸附对齐；
- 右侧加渐隐遮罩，提示「还有更多」。

### 4. 手机端字号偏小
辅助标签（品牌名、角标、场景说明等）仅 10.5–11px，手机上偏吃力。
已在 600px 断点统一抬到 **11.5px**，正文摘要与优点条目抬到 **13px**。

## 四、断点体系

| 断点 | 作用 |
| --- | --- |
| ≥1440px | 宽屏桌面，侧栏加宽 |
| ≤1280px | 桌面略收窄 |
| ≤1120px | 两列布局 |
| **≤900px** | 进入移动端：侧栏变抽屉、隐藏顶栏导航、首屏单列 |
| **≤600px** | 手机细节：单列卡片、字号调整、筛选胶囊加大 |
| ≤380px | 超窄屏微调 |

## 五、相关文件

- `css/style.css` — 教程站样式，≤900px 与 ≤600px 段落为移动端适配
- `css/rental.css` — 设备目录页样式，同名断点
- 所有 HTML 的 `<meta name="viewport">` 已含 `viewport-fit=cover`
