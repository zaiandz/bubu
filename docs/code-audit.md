## 一、已修复的问题

### 1. 搜索无结果时页面一片空白（功能性 bug）
**现象**：在首页搜索一个不存在的关键词，结果数显示 0，但没有任何提示，页面看起来像卡住了。
**原因**：`bindSearch()` 只在「非首页」状态才显示空状态，首页搜索时被完全跳过。
**修复**：
- 有搜索词时统一切到教程视图并调用新增的 `syncEmptyState()`；
- 空状态文案随场景变化：搜不到时显示「没有找到匹配的教程 / 换个关键词试试，或清空搜索框查看全部设备」；
- 清空搜索词时自动清掉空状态并回到首页。

### 2. 清空搜索后停留在空状态（修复 #1 时引入的回归，已一并解决）
清空搜索框原本不会清掉空状态、也不会退出教程视图，现已改为「清空即恢复首页」。

### 3. 侧栏「教程总览」按钮重复代码
目录树模式与卡片列表模式各写了一份几乎相同的创建逻辑（7 行 × 2），
现抽取为公共函数 `createHomeButton(withAnimation)`，差异仅入场动画有无。

### 4. 列表模式的无障碍属性缺失
- 首页按钮缺少 `aria-pressed`，且文案为「首页」与目录树的「教程总览」不一致 → 统一走公共函数；
- 类目按钮、子目录按钮缺少 `aria-pressed` → 已补齐（目录树模式 8 个类目 + 25 个型号均已校验）。

### 5. CSS 重复的 900px 媒体查询块
`css/style.css` 中存在两个独立的 `@media (max-width: 900px)` 块，属性互相覆盖
（如 `.hero` 的 padding、`.to-top` 的尺寸），属于维护隐患。
已合并为单个块，功能与视觉均未变化。备份：`backups/style-before-merge-media.css`。

这是**设计如此**，不是数据缺失：`PRODUCTS` 中的 6 条是「模板」（提供配色、图标、默认文案），
真实教程内容在 `SUBCATEGORY_CONTENT`（25 条），由 `buildDisplayProducts()` 在运行时合成 25 个可展示条目。
侧栏与卡片数量已校验为 25，正常。

### 关于教程缺少 `title` 字段
`SUBCATEGORY_CONTENT` 的条目没有 `title`，但标题取自 `CATEGORIES[].children[].label`，
渲染不依赖该字段，属正常结构。
